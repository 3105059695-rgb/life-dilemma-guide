# 学习地图

这是候选学习需要；不能据此断言提问者存在认知缺陷。

| 编号 | 理论 | 值得补充的判断能力 |
| --- | --- | --- |
| 001 | [墨菲定律](theories/001.md) | 学会把“可能出错”转成有限的风险检查，而不是把担心当成失败预言。 |
| 002 | [深度工作](theories/002.md) | 学会识别需要连续思考的任务，区分切换干扰与知识、目标或精力不足。 |
| 003 | [帕累托最优](theories/003.md) | 学会逐方检查一项调整是否让人变差，并将帕累托有效与分配公平分开讨论。 |
| 004 | [马太效应](theories/004.md) | 学会找出已有成果如何影响下一轮机会的具体通道，避免把落后直接解释为命运。 |
| 005 | [二八定律](theories/005.md) | 学会根据真实贡献分配精力，同时保留短期收益不显眼的必要维护。 |
| 006 | [沉没成本谬误](theories/006.md) | 学会从下一步选择中剔除不可追回的投入，同时保留未来价值、退出代价和现有能力。 |
| 007 | [破窗效应](theories/007.md) | 学会把失序现象拆成可修复的流程和规则预期，同时保留对因果解释的疑问。 |
| 008 | [边际收益递减](theories/008.md) | 学会比较每次追加投入的新增结果，而不是用总成果判断是否应继续加量。 |
| 009 | [后见之明偏差](theories/009.md) | 学会以当时可获得的信息评价决策，把事后清楚与事前可预见区分开。 |
| 010 | [奥卡姆剃刀](theories/010.md) | 学会比较竞争解释所需的额外假设，在不删证据的前提下减少臆测。 |
| 011 | [木桶效应](theories/011.md) | 学会确认真正阻止交付的必要环节，再比较补足、合作与流程调整。 |
| 012 | [华盛顿合作定律](theories/012.md) | 学会用交接、等待和责任划分解释协作低效，而不是凭人数给团队下结论。 |
| 013 | [蝴蝶效应](theories/013.md) | 学会区分非线性系统的初始条件敏感性与日常小行动的谨慎类比。 |
| 014 | [凡勃伦效应](theories/014.md) | 学会区分商品的功能价值、质量信号与身份展示动机，再判断高价吸引力。 |
| 015 | [鲶鱼效应](theories/015.md) | 学会在引入竞争前识别团队低效原因，并同时观察产出、合作与压力。 |
| 016 | [框架效应](theories/016.md) | 学会把不同说法还原为同一基线和实际后果，再判断偏好是否被表述带动。 |
| 017 | [青蛙效应](theories/017.md) | 学会用连续记录辨认渐变恶化，区分合理过渡与底线不断后移。 |
| 018 | [近因效应](theories/018.md) | 学会检查最近一件事是否被赋予过大权重，同时辨别它是否代表真实转折。 |
| 019 | [投射效应](theories/019.md) | 学会把他人的可观察行为与自己填入的动机解释分开，并用安全的核实减少猜测。 |
| 020 | [机会成本](theories/020.md) | 学会找出真正可行的最佳替代方案，并把时间、稳定与照护等价值纳入比较。 |
| 021 | [前景理论](theories/021.md) | 学会识别风险选择中的参照点、结果和概率，理解模型描述偏好而不代替决策。 |
| 022 | [布里丹之驴](theories/022.md) | 学会比较继续犹豫的成本与新增信息的价值，对低风险近似选项设停止点。 |
| 023 | [损失厌恶](theories/023.md) | 学会区分对失去标签的敏感与损失的真实后果，避免把谨慎一律认定为偏差。 |
| 024 | [可得性启发式](theories/024.md) | 学会把容易想起的故事与总体发生率分开，并寻找与自身情况相符的分母。 |
| 025 | [帕金森定律](theories/025.md) | 学会给可控工作划定完成标准与合理时间盒，区分无效扩张和必要工时。 |
| 026 | [北风法则（沟通寓言）](theories/026.md) | 学会在安全且可协商的关系中减少强压，同时清楚表达请求与不可让渡的边界。 |
| 027 | [古德曼定理](theories/027.md) | 学会用停顿容纳完整信息，再以复述核验理解，区分倾听与冷处理。 |
| 028 | [斯坦纳定理](theories/028.md) | 学会让提问和核实带来新信息，同时保留表达自身诉求的空间。 |
| 029 | [红海战略](theories/029.md) | 学会在已有市场中核实竞争维度与真实需求，避免用拥挤或空白直接判定机会。 |
| 030 | [第一性原理](theories/030.md) | 学会把已验证事实、不可跨越约束和可挑战惯例分开，重建一个可检验的方案。 |
| 031 | [复利思维](theories/031.md) | 学会判断投入是否留下可复用成果，以及这些成果有没有实际改善下一次工作。 |
| 032 | [结果思维](theories/032.md) | 学会从真实使用结果设定完成标准，并区分可控制的行动与只能影响的结果。 |
| 033 | [长板效应](theories/033.md) | 学会在必要交付门槛达标后，把资源投入被真实需求认可的优势，而不追求平均优秀。 |
| 034 | [牛鞭效应](theories/034.md) | 学会区分终端实际需求与各层订货变化，并识别供应链中波动被放大的环节。 |
| 035 | [羊群效应](theories/035.md) | 区分多人作出同一选择与多份独立证据，学会判断群体信息是否值得参考。 |
| 036 | [瓦拉赫效应（通俗说法）](theories/036.md) | 把一次任务受挫与整体能力评价分开，并把“瓦拉赫效应”当作出处待核实的通俗提醒。 |
| 037 | [霍桑效应](theories/037.md) | 在被关注后表现变化的情境中，辨认观察效应与资源、考核等竞争解释。 |
| 038 | [纳什均衡](theories/038.md) | 用“别人不变时，我单独改变是否更有利”识别均衡条件，并区分均衡与共同最优。 |
| 039 | [从众效应](theories/039.md) | 识别因接纳压力而改变表达的情况，同时保留价值一致、合作和安全需要等解释。 |
| 040 | [费马原理](theories/040.md) | 理解费马原理属于光学，并识别把领域概念偷换成人生准则的推理。 |
| 041 | [猴子管理理论](theories/041.md) | 区分提供帮助与接管后续责任，让任务负责人、支持范围和权限相互匹配。 |
| 042 | [锚定效应](theories/042.md) | 发现最初数字对后续估计的牵引，并用可比条件建立独立判断区间。 |
| 043 | [自证预言](theories/043.md) | 找出“预期—行为—结果”的中间环节，区分可改变的反馈与外部限制。 |
| 044 | [酒与污水定律](theories/044.md) | 用具体破坏行为及其外溢后果判断合作风险，避免把人或异议当作“污染物”。 |
| 045 | [手表定律](theories/045.md) | 把冲突的评判标准排出层次，区分必要的多指标判断与随意更换尺度。 |
| 046 | [反弹效应](theories/046.md) | 区分念头是否出现与自己能否继续行动，理解反复检查“别想了”可能维持注意。 |

| 049 | [安慰剂效应](theories/049.md) | 区分治疗情境中的期待作用、自然变化与其他原因，避免把改善全归于信念。 |

| 052 | [零和博弈](theories/052.md) | 先界定收益与范围，再判断是否属于零和，避免把所有分歧当作一方必须输。 |
| 053 | [长尾理论](theories/053.md) | 理解分散小众需求形成价值所需的连接与服务条件，区分需求总量和可获得收益。 |
