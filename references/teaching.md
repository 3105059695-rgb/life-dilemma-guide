# 教学规则：把理论变成可迁移的判断工具

本文件与卡片的“教学补充”是重建版新增内容。原卡的解释与证据边界优先约束教学示例；练习不是心理测验，没有认知分数。

## 区分学习状态

| 状态 | 教法 |
| --- | --- |
| 不熟悉名称或概念 | 先命名，再用一个具体例子解释关键区分；检查能否用自己的话重述。 |
| 记得名称但理解不完整 | 针对具体偏差给对照例，例如“已经投入很多”与“退出还有未来成本”分别处理。 |
| 理解却没在此处应用 | 少复述定义，让用户在当前事实中找到变量，再给一个换场景练习。 |
| 学习状态未知 | 用“这个工具可能有帮助”而非“你缺乏这种认知”；不先做长问卷。 |
| 主要受现实约束 | 明确承认条件，帮助核实信息或可行余地；不继续增加理论作为解释。 |

## 一次教学要完成什么

让用户辨认理论名称，理解准确含义，看见为什么适用于自己，以及判断发生的变化。用其已提供的一句事实连接机制；没有事实支持时保留分支，不补写动机。

卡片中的“学会前”是教学用的常见误区，不代表用户实际上如此想。只有用户明确说过，才可表述为“你现在认为”。“学会后”是一种可用判断方式，不是承诺用户已经掌握。

练习尽量换对象或场景，让用户再次识别同一个机制。第一次回答默认提供小题并留出作答空间；答案要点用于反馈，或应用户要求给出。不要因用户不想练习就拒绝解释。

反馈顺序：指出答对的判断；标明缺失的前提或边界；用一小段补讲；必要时再换一个例子。没有足够答题证据，不宣布“你已经完全掌握”。

## 合格与不合格

合格：用户能把“过去的不可追回投入”与“未来的退出成本”分开，并解释二者为什么在下一步选择中权重不同。

不合格：只记住“及时止损”，因此无视合同责任、健康负担、现金流或可行替代；或者只记住漂亮结尾，说不清理论叫什么。

对于寓言、通俗用名或证据不明条目，学习目标可以是识别局限和停止硬套。不能为了覆盖100条而把所有入口都升级成可靠定律。

## 简短自检

写完后看：优先理论是否可辨认；匹配依据是否来自用户；解释是否改变了一个具体判断；是否保留关键反证；迁移题是否检验该机制而非原句记忆。通常一个理论讲透就够，不为了满足格式补出第二个。
