# 人生困境 · 认知补全

**从一句困惑，找到此刻值得补上的理论，并学会下次怎样使用。**

100条认知入口 · 个性化教学 · 判断迁移 · 克制的电影独白

版本：**4.0.0-rebuilt.1**｜中文｜2026-11-06

本项目基于用户提供的 **v3.0.0 普通聊天单文件版**重建，按后来确认的“教学优先”方向补充。它不是原对话中 v4 压缩包的原样恢复，文件数量也不沿用原包的136个。具体来源与改动见 [重建说明](PROVENANCE.md)。

## 它怎样帮助你

你只需要描述困惑，不必先知道理论名称。例如：

> 我做了半年项目，没什么结果，但一想到放弃，就觉得之前的时间全白费了。我应该补什么认知？

AI先指出最值得学的工具，例如沉没成本与机会成本，再结合你的原话解释：哪些投入已经不可追回，哪些条件影响未来，以及继续会放弃什么可行选择。目标是让你说得清理论名称、适用理由、用法与边界。

通常讲透1—2条，最多3条。不会把100条一次列出来，也不会把资源不足、价值冲突或他人伤害都归因于你的认知不足。电影感来自具体矛盾和克制推演，不能用漂亮台词替代解释。

## 使用

**支持 Skills 的工具**：下载整个仓库，保留文件夹名称 `life-dilemma-guide`，按目标工具支持的方式添加整个目录。入口是 [SKILL.md](SKILL.md)，不能只复制入口而遗漏参考资料。项目不依赖特定模型API，也没有联网调用服务。

可以直接说：

> 请用 life-dilemma-guide，告诉我目前最值得补充什么理论，先把一个讲懂，再教我怎样应用。我的困惑是：……

**普通聊天**：上传 [standalone.txt](standalone.txt)，再说：

> 请将附件作为本次对话的教学资料。根据我的困惑，选择并读取相关完整卡片，解释理论名称、为什么适用、判断如何变化及使用边界。无法读取时明确说明。我的困惑是：……

上传文件是本次对话的参考资料，不等于永久安装或训练模型。长文件的读取效果取决于目标工具；本项目未作全平台兼容性认证。更多见 [安装与试用](INSTALL.md)。

## 100条的边界

保留全部原编号，不代表100项独立、可靠的科学定律。卡片区分研究概念、领域模型、实务方法、比喻与存疑用名。#077/#087重复；#026/#099同源寓言；#076/#094只作查词和纠偏。不得用重复条目凑独立证据。

25条来源记录从原单文件拆出，其中历史“已检索/已核读”描述属于v3材料的自述；**本次没有重新完成文献核验**。生活应用、教学题与表达句不冒称论文直接结论。

## 本地检查与维护

正常使用Skill无需运行脚本。维护脚本使用现有 Python 3.9+ 标准库，无需安装依赖：

```bash
python scripts/build.py --check
python scripts/validate.py
python -B -m unittest discover -s tests -p "test_*.py" -v
python scripts/query.py --id 6 20 --full
python scripts/query.py --search "不甘心"
```

关键词查询只给候选，不是语义搜索、心理测评或最终匹配。修改知识库的 `teaching` 字段后，运行 `python scripts/build.py` 生成卡片、索引、学习地图、覆盖题和单文件版。不要直接修改生成文件；构建会替换这些生成文件。原卡正文哈希用于检测意外改写。

实际检查记录见 [VALIDATION.md](tests/VALIDATION.md)。结构与脚本检查通过，不能证明实际AI教学效果；[场景题](tests/cases.json) 与 [100道覆盖题](tests/coverage.json) 的目标模型测评状态均为未运行。

本项目不自动保存困境或上传对话。不要将真实咨询记录和身份信息提交到公共仓库；AI宿主对上传内容的处理以其设置为准。许可证尚未选定，本仓库不宣称采用任何开源许可。
